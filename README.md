# Carburanti, la classifica delle province

Dashboard di Instant Analytics sui prezzi dei carburanti comunicati dai gestori all'Osservaprezzi del MIMIT (open data, licenza IODL 2.0). Viene rigenerata automaticamente ogni mattina.

Ultima estrazione MIMIT pubblicata: **2026-09-27** (prezzi in vigore alle ore 8 di quel giorno).

Pagina: https://agapitosantangelo.github.io/carburanti/carburanti_dashboard.html

File: `carburanti_dashboard.html` (dashboard, un solo file offline), `carburanti_province.csv` (una riga per provincia), `ultima_estrazione.txt` (data dell'estrazione pubblicata).
